# Kia Motors Sales Dashboard | Microsoft Excel

## Project Overview
This project presents an interactive sales dashboard for analyzing Kia Motors sales data using Microsoft Excel. It helps summarize key business performance metrics and explore sales trends through visualizations.

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Cost of Goods Sold (COGS)
- Total Orders

## Dashboard Features
- Month-wise sales trend analysis
- Region-wise sales performance comparison
- Top 5 car models by sales
- Interactive filters for exploring data
- Visual representation of key business metrics

## Tools Used
- Microsoft Excel
- Data Analysis
- Data Visualization
- Dashboard Design

- Improved skills in analyzing sales performance
- Learned to present business data using charts, KPIs, and filters
